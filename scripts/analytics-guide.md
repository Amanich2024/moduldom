# Аналитика Загородной студии — 26.11.2026

Счётчик .ru: 114379195. Одинаковые события на мобильной и компьютерной версиях. 32 пользовательские цели (12 прежних + 20 новых); автоцели Яндекса отдельно. PDF, переход по каналу связи и обсуждение проекта добавлены в избранное.

## Где смотреть
- Цели / Конверсии: достижения и доля визитов с действиями.
- Отчёты → Содержание → Параметры событий: раскрыть цель и параметры дома, комплектации, канала и места нажатия.
- Параметры визитов: builder_project — снимок выбранного проекта при изменении, итогах, обращении и PDF; site_part — версия сайта.
- Стандартные отчёты: источники, UTM, устройства/ОС, география, новые/вернувшиеся посетители. Вебвизор и карта кликов включены.

## События
- open_house / open_built: открытие типового / построенного дома, ID и публичное название. Срабатывают и при прямой ссылке.
- photo_view: фотография появилась минимум на 35% в видимой области; не означает прочтение подписи. Один раз на фото за открытие карточки.
- plan_view: показ плана; photo_zoom: увеличение.
- house_engaged: активный просмотр карточки 30 секунд; house_engagement: итоговое активное время, число фото и просмотр плана при закрытии/смене карточки.
- builder_click / builder_open / builder_started: переход, открытие, первое действительное изменение.
- builder_change: объединённые изменения с задержкой 1 секунду, не каждый пиксель перетаскивания.
- builder_option / builder_plan_edit / builder_view: опции, изменения стен/дверей/окон, виды фасадов.
- builder_active_30/60/180/300: активные пороги. builder_time: active_seconds — накопленное время в этом открытии, active_delta_seconds — приращение между отчётами. Не суммировать накопленные значения!
- builder_summary / builder_request: итоги / нажатие перехода к обсуждению проекта. Заявка не считается полученной.
- builder_share: ссылка скопирована, системное меню завершило передачу или открыто окно отправки Telegram; смотреть outcome.
- pdf_start / pdf_download / pdf_error: запуск / файл сформирован и передан браузеру / ошибка. pdf_download не подтверждает сохранение на диск: браузер не даёт такого подтверждения странице.
- contact_click: channel = phone, vk_message, telegram_message, vk_community, telegram_channel, avito, manager_chat; placement = header, house_card, catalog_card, builder_summary, footer, page. after_pdf/after_builder/after_summary — предыдущие шаги в сессии вкладки (обновление флагов с тайм-аутом 30 минут).
- call_click / write_click сохранены для истории. Не складывать их с contact_click: это те же действия в разных разрезах.
- catalog_filter / catalog_equipment: фильтр и выбор тёплого контура / чистовой отделки.
- section_view: переход по верхнему меню.
- site_error: категория ошибки JS, картинки, сохранения; без текста исключения или пользовательских полей.

## Проверки и ограничения
Локальные адреса не отправляют события в счётчики. ?analytics_debug=1 пишет последние 100 событий в скрытый DOM output#studio-analytics-debug; на рабочем домене такие события имеют traffic_type=qa. Для отчётов посетителей исключить traffic_type=qa. Обычные проверки без этого флага остаются обычными визитами.
Активное время учитывается только при видимой вкладке и активности за последние 60 секунд, таймер каждые 5 секунд. Закрытие страницы может не доставить финальный запрос; пороги сохраняются отдельно.
Собственный свободный текст, телефоны/имена посетителей, Telegram ID и сообщения не передаются нашими параметрами. Сбор стандартных данных Метрики/Вебвизора остаётся в настройках существующего счётчика.
История до установки новых событий не восстанавливается. Блокировщики могут мешать сбору.
