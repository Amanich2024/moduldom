# Загородная студия — единый проект

Основной источник информации — data/catalog.json.
Фотографии находятся в img и katalog/img.
Цены, параметры, комплектации, фотографии, контакты и тексты меняются в этом файле.
Дизайн страниц находится в templates. Содержимое HTML в корне и katalog генерируется сборкой.

После изменения данных запускайте scripts/build.py через Python 3.
Сборка проверяет цены, уникальность ID, подписи и наличие изображений.
Она обновляет Telegram-каталог, браузерный каталог и опубликованные дизайнерские страницы.
Для появления изменений у покупателей нужно опубликовать собранный проект на GitHub Pages.
Компьютер после публикации можно выключить.

Раздел projects содержит типовые проекты, built — построенные дома.
equipment — комплектации, contacts — контакты, pages — тексты отдельных страниц.
assets — общие ссылки на изображения.
Значения площадей перенесены из опубликованной версии. Их согласование остаётся отдельной задачей.

## Управление каталогом

Панель: https://zagorodnaya-studiya.ru/admin/ — инструкция: /admin/guide.html.
Поля и черновики можно редактировать без входа; запись в репозиторий требует GitHub-пользователя с push-доступом и его fine-grained token только для этого репозитория (Contents: read/write, Actions: read). Ключ находится только в памяти вкладки, не попадает в файлы и копии. Общего пароля в публичном JavaScript нет.

Публикация создаёт один коммит с данными и новыми изображениями и обновляет main без force. Проверка head SHA предотвращает перезапись параллельных правок. Workflow `.github/workflows/publish.yml` проверяет и собирает сайт, затем публикует артефакт в Pages. Pages должен использовать source GitHub Actions (`build_type: workflow`). Старый успешный сайт остаётся доступен при ошибке проверки.

`status`: published (по умолчанию), draft, archived. Скрытие применяется к публичному data/catalog.js и настольному портфолио. Исходный JSON и репозиторий публичны — черновики не являются конфиденциальными. Порядок built одинаков для каталога и Story, первый опубликованный объект — главный.

`priceOnRequest: true` скрывает точные цены типового дома в каталоге, сохраняя их для редактирования.
Новые фотографии преобразуются в WebP в браузере. Галерея built использует ключ без расширения, проекты — путь внутри katalog. Оригиналы новых файлов до публикации хранятся в памяти вкладки; экспорт копии включает их. Авточерновик localStorage сохраняет только данные. Обычная работа не удаляет старые файлы.

Перед передачей: передать владельца домена, репозитория, бота и Метрики; проверить самостоятельное создание, публикацию и восстановление объекта; сохранить git bundle вне GitHub. После переноса репозитория обновить REPO в admin/admin.js. Создание новых типов конструктора, CRM, аккаунты покупателей и независимый сервис рассылки аналитики в эту панель не входят.
