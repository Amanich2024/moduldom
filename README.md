# Загородная студия — единый проект

Основной источник информации — data/catalog.json.
Фотографии находятся в img и katalog/img.
Цены, параметры, комплектации, фотографии, контакты и тексты меняются в этом файле.
Дизайн страниц находится в templates. Содержимое HTML в корне и katalog генерируется сборкой.

После изменения данных запускайте scripts/build.py через Python 3.
Сборка проверяет цены, уникальность ID, подписи и наличие изображений.
Она обновляет Telegram-каталог, браузерный каталог и опубликованные дизайнерские страницы.
Для появления изменений у покупателей нужно опубликовать собранный проект на GitHub Pages.
Компьютер после публикации можно выключить.

Раздел projects содержит типовые проекты, built — построенные дома.
equipment — комплектации, contacts — контакты, pages — тексты отдельных страниц.
assets — общие ссылки на изображения.
Значения площадей перенесены из опубликованной версии. Их согласование остаётся отдельной задачей.
